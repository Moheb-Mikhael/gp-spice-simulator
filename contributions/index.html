Contributions

Ways to contribute to SPICE Suite and the broader Egyptian EDA ecosystem.

How to Contribute

💻

Code & Features

Check our GitHub repository for open issues, feature requests, and pull requests. Every contribution counts — from bug fixes to new simulation features.

📝

Documentation

Help improve command docs, write tutorials, or translate existing content into Arabic. Clear documentation makes EDA accessible to everyone.

🎨

Design & UI

Contribute to the visual identity — icons, themes, mockups, or front-end improvements that make the tool more welcoming for Egyptian students.

💬

Community & Support

Answer questions in Discussions, review pull requests, or help onboard new contributors. Growing the community is as valuable as growing the codebase.
