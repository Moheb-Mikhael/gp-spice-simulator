Frequently Asked Questions

Common questions about Arachnode — from running your first simulation to advanced post-processing.

Open the Web Simulator , and you’ll see a default RC low-pass filter netlist already loaded. Click Run Simulation to execute it. The console shows output logs, and if a plot command is in the netlist, the Plot tab will display the waveform automatically.

Arachnode uses standard SPICE netlist syntax. Any netlist that follows the traditional SPICE format (component lines, .control / .endc blocks, analysis commands) should work. Examples are provided in the Load Example dropdown inside the simulator.

You can use the export command inside your .control block to write data to a CSV file. For example: export data.csv V(in) V(out) . The exported file is available for download in the browser version, or written to disk in the desktop app.

The calc command lets you evaluate arithmetic expressions on waveforms. You can add, subtract, multiply, and divide signals, apply functions like abs() , sqrt() , sin() , log() , and reduction functions such as max() , min() , avg() , and rms() .
